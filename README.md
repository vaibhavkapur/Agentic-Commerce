# Agentic Commerce

## Getting started

```bash
git clone https://github.com/vaibhavkapur/Agentic-Commerce.git
cd Agentic-Commerce/projects/Agent-Authorization-Wallet-Merchant-Trust-Gateway
```

Choose a project below and follow its README. Run setup, tests, and demos from that project's directory. When a guide refers to the repository root, use the corresponding `projects/<name>/` directory.

The projects run independently. Check each project's setup instructions for the fixtures, source data, and credentials it uses.

## Projects

- [Agent Authorization Wallet + Merchant Trust Gateway](projects/Agent-Authorization-Wallet-Merchant-Trust-Gateway/) — Delegate one purchase to an agent and verify its identity, spending authority, and transaction details at the merchant.
- [Agent Services Marketplace](projects/Agent-Services-Marketplace/) — Discover paid research services through an MCP catalog and track spending, delivery, and simulated x402 or MPP settlement.
- [Agentic Commerce Protocol Test Lab](projects/Agentic-Commerce-Protocol-Test-Lab/) — Test local checkout implementations against versioned protocol profiles and compare their behavior when requests or responses fail.
- [Autonomous Price-Watch Buyer](projects/Autonomous-Price-Watch-Buyer/) — Watch one product and buy it once when the delivered price meets the buyer's signed terms.
- [Cross-Merchant Procurement Agent](projects/Cross-Merchant-Procurement-Agent/) — Compare supplier quotes and complete an approved purchase within budget and delivery constraints using MCP, A2A, UCP, and ACP.
- [Accounts Payable Exception Agent](projects/Accounts-Payable-Exception-Agent/) — Investigate invoice exceptions, collect missing evidence, and export a payment instruction after human approval.
- [Merchant Integration Copilot](projects/Merchant-Integration-Copilot/) — Inspect an Express payment integration, review a proposed patch, and check how it handles sample webhooks.
- [Payment Incident Investigator](projects/Payment-Incident-Investigator/) — Reconstruct a payment incident from its event history, then replay a stored webhook with operator approval and verify the outcome.
- [Security Deposit Claims](projects/Security-Deposit-Claims/) — Import claims and supporting documents, extract itemized charges, and apply coverage rules while preserving each claim's decision history.
